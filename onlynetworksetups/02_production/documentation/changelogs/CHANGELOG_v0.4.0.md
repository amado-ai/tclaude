---

## Summary

V0.4.0 builds the reusable backbone all missions from V0.5.0 onward will run on. No new
content missions ship in this version. The goal is to eliminate custom per-mission hacks
and replace them with data-driven, scalable systems.

---

## Systems Added

- [ ] Mission framework and objective manager (FT-002).
- [ ] Diagnostics tablet — Device Status, Connection Map, Signal Meter, Event Log panels (FT-003).
- [ ] Hint manager — timed, contextual hints with escalation logic.
- [ ] Glossary / help system — in-game definitions for networking terms.
- [ ] Skill cards — post-objective knowledge cards shown on objective completion.
- [ ] Scoring framework — time-based and mistake-count scoring per mission.
- [ ] Save / load framework — mission progress, settings, and score persistence.
- [ ] Reusable DeviceStateMachine data-driven config (device definitions as ScriptableObjects).
